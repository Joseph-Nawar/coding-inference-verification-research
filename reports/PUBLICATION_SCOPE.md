# Public research snapshot

The original research history remains in the local workspace. The public history has two milestones for the P0 baseline and the subsequent EvalPlus regression. Public commits use the GitHub account's platform-provided noreply address.

The baseline snapshot omits the private split namespace, split commitment and task IDs. It also removes workstation-specific paths from the command notes and the generated lock header. Dependency versions and artifact hashes in the lock are unchanged. The public baseline checksum manifest covers the published versions of those files.

The public repository includes the research protocol, safe reports and independently authored synthetic fixtures. Benchmark data, canonical solutions, model weights, third-party source archives, expected outputs, protected task IDs and raw experiment logs are held outside Git. The fixture documentation points to separately licensed source archives and package artifacts. No standalone reuse license has been added.
