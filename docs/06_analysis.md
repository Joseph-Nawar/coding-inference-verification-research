# 06 — Analysis and scientific decisions

Unit of analysis: task, not individual candidate or test. Equal task weighting overall and benchmark-specific metrics. Record denominators and missingness. Include all generated attempts in intention-to-evaluate population; model syntax/truncation/invalid selector counts as unsuccessful, infrastructure-invalid runs separately reported and never replaced silently. If scoring failure prevents label, give bounds/sensitivity and technical blocker. No cherry-picking tasks or prompt changes midrun.

Let Y_ij be full official benchmark correctness and Z_ij H-only correctness when eligible. For pool size k, O_i=max_j Y_ij; S_i=Y of selected candidate (0 if invalid selection), initial I_i=Y_i0. Estimate mean O, mean S, mean I, O-S headroom, S-I gain; note O-S nonnegative if selection is from pool. Random policy expected success = sum(Y)/k. Unbiased pass@k estimate per task = 1 - C(n-c,k)/C(n,k), averaged over tasks (n fixed, c correct, conventions for n-c<k). Distinguish from empirical prefix oracle. Report duplicate rates and dependence caveats. For V acceptance, false accept denominator all Y=0, false reject denominator all Y=1; also report P(Y=0|V passes) and raw counts, do not conflate. Evaluate H-only in eligible tasks and report exposure limitations.

E2: paired differences in selection accuracy by arm, deterministic comparators, restricted mixed-pool conditional analyses; explicitly label conditional strata, report sample sizes. For each evidence signature, mixed Y cluster count and ambiguity; no oracle-based policy as deployable result. Distinguish existence of a correct candidate, observable separation and actual selection. E3: paired effects R10-R00, R11-R01 (context); R01-R00, R11-R10 (feedback); interaction (R11-R01)-(R10-R00). Report original/no-op and conditional repair/regression. For initial correctness p, r=P(final correct|initial incorrect), g=P(final incorrect|initial correct), delta=(1-p)r-pg, if common population. If denominators zero report NA. E4: within-task panel contrasts; label validity and separation metrics with counts, paired 2x2 comparisons. H-only analyses separate from official score. Exploratory associations do not establish latent causes.

Uncertainty: 2,000 paired task-cluster bootstrap resamples, stratified by benchmark, fixed analysis seed; resample entire task records preserving all candidates, test panels and arms. Report percentile 95% intervals, counts and benchmark-specific effects. Sparse conditional denominators and small sample sizes may make intervals unstable: report number of valid replicates, NA if insufficient, avoid overinterpretation. Include raw paired contingency counts. Distinct generation seeds nested within tasks are not independent tasks; if later multiple seeds, use task-level mean or hierarchical model. No multiplicity-adjusted confirmatory inference yet; label all intervals exploratory and no p-value fishing. Confirmatory sample size and primary estimand determined separately from exploratory variance and practical effect, not an arbitrary cutoff.

Cost accounting: record actual input tokens (post-template), output tokens (including invalid/truncated), calls, elapsed generation/prefill/decode if available, runner invocations/tests, timeouts, total wall, peak RSS and MLX/VM allocations separately. Include selection/repair overhead; don't add overlapping memory measurements or equate token count with FLOPs. Report correctness versus realized compute and budget limits; no extrapolation to production performance.

## Evidence-guided decisions (not all-or-nothing)
- E1 low oracle-any: investigate generation competence, task difficulty or model choice; don't infer verification is useless generally. High oracle and weak selection: prioritize E2/E4. High actual selection: focus repair, regressions, cost or harder tasks rather than invent selector.
- E2 valid labels fail to separate candidates: evidence acquisition/quality branch. Deterministic V+D selects correctly but LLM misses: interpretation branch. Both work: evaluate evidence cost and generalization, not invented failure.
- E3 feedback helps: investigate information diversity and localization. Context hurts: test anchoring explanation vs prompt length/quality. No repair gain: examine model capability or actionable evidence. Correctness regressions: investigate preservation and verifier false rejection. None significant on small n is not proof of no effect.
- E4 wrong labels degrade selection: quantify dependence and test stronger comparators; no novelty claim for known invalid-test effect. Weak discrimination despite valid labels: focus information acquisition. No useful effect: reconsider branch and document.

Report practical magnitude, uncertainty, competing explanations, known literature, remaining confounds, feasible next test and expected information value. At phase boundary choose CONTINUE_BRANCH / REVISE_SETUP / PAUSE_BRANCH / EXPLORE_OTHER_HYPOTHESIS / REVIEW_PROGRAM / TECHNICAL_BLOCKED. Only researcher can close entire program. Never claim original discovery based solely on benchmark difference or lack of literature hit.
